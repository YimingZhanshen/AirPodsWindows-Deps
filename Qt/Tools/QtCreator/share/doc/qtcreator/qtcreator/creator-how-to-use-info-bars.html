Use info bars instead of pop-ups

By default, Qt Creator uses pop-up dialogs to display messages that require user interaction.

You can choose to use banner-style info bars instead of pop-ups.

To use info bars:

  1. Select Preferences > Environment > Interface.

  2. Select Prefer banner style info bars over pop-ups.
