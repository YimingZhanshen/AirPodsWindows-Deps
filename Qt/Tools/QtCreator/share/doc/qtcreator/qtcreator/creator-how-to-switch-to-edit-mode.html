Switch to Edit mode

To move to the Edit mode and currently active file, select Esc.

If you already are in the Edit mode:

  • The first time you select Esc, the focus moves to the editor
  • The second time you select Esc, secondary windows are closed

See also How To: Edit Code and Edit Mode.
