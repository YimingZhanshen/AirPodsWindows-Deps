Use external text editors

To open files for editing in the default text editor for your system:

  1. Right-click the filename in one of the following views to open a context menu:
    • Edit mode
    • File System
    • Open Documents
    • Projects
  2. Select Open With > System Editor.

Switch between editor types

To switch between editor types, right-click the filename and select Open With > Cycle to Next Editor.

You can assign a keyboard shortcut for Cycle to Next Editor. For more information, see Assign keyboard shortcuts.

Add editors to Tools menu

You can add menu items for opening the file you are currently viewing in an external editor to Tools > External > Text. The current example commands are Edit with Notepad on Windows and Edit with vi on Linux and macOS.

Qt Creator looks for the editor path in the PATH environment variable of your operating system.

See also Use external tools.
