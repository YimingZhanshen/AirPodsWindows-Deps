Add bookmarks to help pages

Add bookmarks to useful help pages to easily find them later in the Bookmarks view. Either use the page title as the bookmark or change it to any text. You can organize the bookmarks in folders in the view.

To add a bookmark to an open help page:

  1. Select (Add Bookmark) on the toolbar.
  2. In the Add Bookmark dialog, select OK to save the page title as a bookmark in the selected folder.

Import and export bookmarks

To import and export bookmarks, go to Preferences > Help > General and select Import Bookmarks or Export Bookmarks.

See also How To: Read Documentation.
