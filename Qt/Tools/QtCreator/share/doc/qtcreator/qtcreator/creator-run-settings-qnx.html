QNX Run Settings

To specify settings for running applications on the Run device that you select for a kit, go to Projects > Run Settings.

To run and debug an application on a QNX device, select Manage device configurations to create a connection between Qt Creator and the device.

Settings for QNX Neutrino devices are very similar to those for remote linux devices.

See also How To: Develop for QNX, How To: Manage Kits, Remote Linux Run Settings, Configure projects for running, and Kits.
