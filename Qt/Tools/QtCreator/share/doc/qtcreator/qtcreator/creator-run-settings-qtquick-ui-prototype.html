Qt Quick UI Prototype Run Settings

Settings for running Qt Quick UI Prototype projects (.qmlproject).

To specify settings for running applications on the Run device that you select for a kit, go to Projects > Run Settings.

Note: Select the Desktop device type for the Run device in the kit.

The following table summarizes the settings for running Qt Quick UI Prototype projects (.qmlproject).

SettingValue
Override device QML ViewerQt QML Viewer to use.
Command line argumentsArguments to pass to the executable.
Main QML fileFile to start Qt QML Viewer with.
X11 forwardingSelect Enable to show a remotely running X11 client on a local display.

See also Create Qt Quick UI Prototypes, Activate kits for a project, Configure projects for running, and Kits.
