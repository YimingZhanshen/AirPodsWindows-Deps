Boot to Qt Run Settings

To specify settings for running applications on the Run device that you select for a kit, go to Projects > Run Settings.

To run and debug an application on a Boot to Qt device (commercial only), create connections from the development host to the device and add the device configurations to kits.

Select Manage Kits to add devices to kits.

The run settings display the path to the executable file on the development host and on the device.

See also How To: Develop for Boot to Qt, How To: Manage Kits, Configure projects for running, Kits, and Boot to Qt Deploy Configuration.
