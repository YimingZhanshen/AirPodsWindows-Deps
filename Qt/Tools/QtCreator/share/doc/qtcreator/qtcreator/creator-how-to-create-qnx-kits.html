Create kits for QNX Neutrino devices

To generate a build and run kit for QNX Neutrino devices:

  1. Go to Preferences > Devices > Devices.
  2. Select Add > QNX Device > Start Wizard to add a QNX Neutrino device.
  3. Select Apply to fetch the information needed for creating kits.
  4. Go to Preferences > SDKs > QNX.
  5. Select Create Kit to create a kit for a particular platform.

  6. Activate the kit for your project.

See also How To: Develop for QNX and Activate kits for a project.
